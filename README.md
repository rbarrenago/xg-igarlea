# xG igarlea ⚽

xG (Expected Goals / gol-probabilitatea) ereduaren simuladore interaktibo bat, **Ikaskuntza Automatikoko Sistemak** moduluko (5072, IA eta Big Data espezializazio-ikastaroa) klaserako. Jaurtiketa bat zelaian jarri, gol-probabilitatea begiz asmatu eta eredua erakusten du.

Erregresio logistiko batean oinarritzen da: `xG = σ(w·distantzia + w·angelua + b)` — ikasleek ariketan eskuz eraikitzen duten eredu bera.

**Simulador interactivo del modelo xG (goles esperados)** para la asignatura Sistemas de Aprendizaje Automático. Coloca un disparo, adivina el xG y revélalo, con el mismo modelo de regresión logística que el alumnado construye en el ejercicio.

## Erabilera / Uso

Fitxategi bakar bat da (`index.html`), mendekotasunik gabe. Nabigatzailean ireki, edo GitHub Pages bidez zerbitzatu.

Es un único archivo (`index.html`) sin dependencias. Ábrelo en el navegador o publícalo con GitHub Pages.
